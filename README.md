# The Brew Moon Cafe

A responsive static website for The Brew Moon Cafe, built with HTML, CSS, and vanilla JavaScript.

## Run locally

No build step or package installation is required. From the project folder, run:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000). Stop the server with `Ctrl+C`.

You can also open `index.html` directly in a browser.

## Features

- Responsive layout for desktop and mobile screens
- Searchable menu with category and vegetarian/non-vegetarian filters
- Client-side cart with item variants and quantity controls
- Cafe information and a Google Maps directions link

## Project files

- `index.html` — page structure
- `styles.css` — layout, colors, and responsive styles
- `script.js` — menu, filters, and cart behavior
- `assets/logo.png` — cafe logo

Google Fonts are loaded when available; local system font fallbacks are provided.
